I wanted to get back a bit into game development, so after playing around a bit I decided to join a game jam in January/February, so that I had to make and show something. 

The graphics are very simple - partially due to the short time frame, partially due to working alone, partially due to working full-time, and partially due to using SDL2 as the graphics library and writing my own engine (in Rust!).

The general theme of the mechanics is using game elements that aren't typically used for gameplay.

You can find the game on [itch](https://bobobcat.itch.io/toggle), and the code on [GitHub](https://github.com/bill-bateman/toggle).
